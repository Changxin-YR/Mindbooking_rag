## 3. 已修复与补全

- Reader、Writer、Admin 使用真实 Bearer 会话；Admin 不接受 Reader account session。
- 后端私有 API 校验 Session、主体类型和资源归属，避免仅依赖前端隐藏按钮。

- Staff Account 独立凭据、Session、设备、MFA factor、角色/权限 migration；Admin 入口只允许 Staff session。
- SearchPort 支持多字段查询、过滤、排序、纠错和不可用时降级。
- Agent Gateway 仅通过注册的 Tool/Resource 回调访问业务服务；高风险写入被拒绝并提供审计记录入口。
- Reader、Writer、Admin 页面补充登录态、加载/错误/空状态和真实 API 请求；移除固定 demo 身份。
