# V1.2 Platform Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the V1.2 web novel platform as a runnable pnpm/Python monorepo with real API, MySQL migrations, three web shells, and progressively integrated Wave gates.

**Architecture:** A FastAPI modular monolith owns explicit DTOs and application ports. Reader, Writer, and Admin are separate TypeScript apps backed by the same API contracts. MySQL is the transactional source of truth; Redis, RabbitMQ, OpenSearch, ClickHouse, MinIO, and observability run as Compose services with local adapters.

**Tech Stack:** Python 3.14, FastAPI, Pydantic v2, SQLAlchemy 2, Alembic, MySQL 8.4, Redis, RabbitMQ/Celery, OpenSearch, ClickHouse, MinIO, Nuxt 4, Vue 3, Vite, TypeScript, pnpm, Vitest, pytest, Playwright, Docker Compose.
