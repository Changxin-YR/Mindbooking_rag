# V1.2 Completeness Workstreams Design

**Goal:** Continue the V1.2 implementation toward launch readiness by closing locally verifiable gaps without misrepresenting external-provider readiness.

**Scope:**

1. Expose durable Agent audit facts through an explicit staff-only DTO/API.
2. Add an outbox-driven search projection handler that updates only public content facts and remains idempotent.
3. Add a ContentAccess-gated basic TTS API with deterministic playback metadata, while leaving production voice-provider credentials as a deployment gate.

**Boundaries:** Agent audit remains append-only and uses the existing SQL sink. Search receives events through the Governance/Outbox port and never becomes the business source of truth. TTS calls the same chapter access policy as text and never bypasses entitlement or visibility checks. No new runtime dependency or provider-specific production claim is introduced.

**Verification:** Each workstream adds a failing regression test first, then the minimal implementation, focused tests, full backend tests, frontend tests/builds, and the existing Compose smoke suite. Coverage remains `PARTIAL` for external credentials, full role browser E2E, and unresolved policy/legal/tax decisions.
